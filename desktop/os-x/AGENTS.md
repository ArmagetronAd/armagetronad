# MacOS/ Directory

## Summary
macOS-specific files and project configurations for Armagetron Advanced.

## Details

The MacOS directory contains macOS-specific files including Xcode project files, build configurations, and other resources needed for building and running Armagetron Advanced on macOS platforms.

## Directory Structure

```
.
├── Armagetron Advanced.xcodeproj/   # Xcode project for main application
├── Armagetron.pbproj/              # Legacy Xcode project file
└── build_tools/                     # macOS build tools and scripts
```

## Technologies

- **Platform**: macOS
- **IDE**: Xcode
- **Language**: Objective-C (for native integration)

## Key Patterns

- Native macOS application bundle
- Xcode project organization
- Platform-specific build configuration
