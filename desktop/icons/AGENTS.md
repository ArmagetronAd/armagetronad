# desktop/icons/ Directory

## Summary
Icon files for desktop integration at various sizes.

## Details

The icons directory contains icon files for Armagetron Advanced desktop integration. Icons are provided at multiple standard sizes to support various desktop environments and display resolutions.

## Directory Structure

```
.
├── 128x128/    # 128x128 pixel icons
├── 16x16/      # 16x16 pixel icons (favicon size)
├── 32x32/      # 32x32 pixel icons
├── 48x48/      # 48x48 pixel icons
├── 64x64/      # 64x64 pixel icons
```

## Technologies

- **Formats**: PNG (Portable Network Graphics)
- **Purpose**: Desktop and application icons

## Key Patterns

- Multi-resolution icon support
- Standard icon sizes for desktop environments
