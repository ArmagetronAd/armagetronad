# batch/win32/ Directory

## Summary

Windows-specific batch build scripts and utilities for Armagetron Advanced.

This directory contains Windows-specific batch build scripts and utilities used for building and packaging Armagetron Advanced on Windows platforms. These scripts support the Windows build process, distribution creation, and other Windows-specific development tasks.
