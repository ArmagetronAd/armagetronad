# docker/images/steamcmd/ Directory

## Summary
SteamCMD Docker base image for Steam integration.

## Details

The steamcmd directory contains the Dockerfile and configuration for a SteamCMD-based image. SteamCMD is the command-line version of the Steam client, used for downloading and managing Steam content from the command line.
