# src/doc/Content_Creation/ Directory

## Summary
Documentation and tutorials for creating custom game content, primarily maps and worlds.

## Details
This directory contains guides for content creators, focusing on map design and the World format specification. The main tutorial, Howto-Maps.txt, provides a comprehensive reference for the XML-based World format (version 0.1), covering format overview, World/Map/Field elements, Axes configuration, Spawn points, Walls, and best practices with examples.

.
└── Howto-Maps.txt   # Tutorial for map designers on World format
