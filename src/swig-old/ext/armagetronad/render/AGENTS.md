# src/swig-old/ext/armagetronad/render/ Directory

## Summary

Legacy SWIG interface definitions for Armagetron Advanced's render module.

## Details

This directory contains legacy SWIG interface files that expose the render module's functionality to scripting languages. These represent an older approach to exposing rendering functionality through SWIG.
