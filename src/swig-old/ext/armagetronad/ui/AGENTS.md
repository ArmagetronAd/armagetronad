# src/swig-old/ext/armagetronad/ui/ Directory

## Summary

Legacy SWIG interface definitions for Armagetron Advanced's UI module.

## Details

This directory contains legacy SWIG interface files that expose the user interface module's functionality to scripting languages. These represent an older approach to exposing UI functionality through SWIG.

## Directory Structure

```
. (Legacy UI-related SWIG interface files)
```

## Technologies

- **SWIG**: Simplified Wrapper and Interface Generator
- **Module**: UI functionality
- **Status**: Legacy

## Integration

- **UI Module**: Exposes UI functionality to scripting
- **Legacy System**: Part of legacy SWIG configuration
- **Historical Context**: Older approach to UI module SWIG interfaces
