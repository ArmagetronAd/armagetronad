# textures/tutorials/ Directory

## Summary

Tutorial-specific textures and visual guides for Armagetron Advanced's tutorial system.

## Details

This directory contains texture resources used specifically for the game's tutorial system. Each subdirectory corresponds to a different tutorial or game mode, providing visual guides, examples, and instructional graphics to help players learn various aspects of the game.

The tutorial textures cover different gameplay modes, techniques, and strategies, offering visual assistance to new and experienced players alike.

## Directory Structure

```
.
├── clipart/         # Clipart-style tutorial graphics and generic tutorial elements
├── conquest/        # Conquest mode tutorial textures and visual guides
├── doublegrind/     # Double Grind mode tutorial textures
├── grinding/        # Grinding technique tutorial textures
├── navigation/      # Navigation and movement tutorial textures
├── speedkill/       # Speed kill tutorial textures
├── speedkilldefense/# Speed kill defense technique tutorials
├── survival/        # Survival mode tutorial textures
└── teamstart/       # Team start and coordination tutorial textures
```

## Technologies

- **Image Formats**: PNG, JPG
- **Purpose**: Tutorial visualization and player education
- **Rendering**: Used by the rendering system for tutorial display

## Integration

- **Tutorial System**: Used by the game's tutorial and help system
- **Resource Management**: Loaded and managed by the resource system
- **UI Integration**: Displayed in tutorial dialogs and interfaces

## Tutorial Content

Each subdirectory provides visual materials for specific tutorial topics:

- **clipart/**: Generic tutorial elements and clipart-style graphics
- **conquest/**: Tutorial for conquest game mode mechanics
- **doublegrind/**: Double grind technique tutorials
- **grinding/**: Basic grinding technique tutorials
- **navigation/**: Movement and navigation tutorials
- **speedkill/**: Speed kill technique tutorials
- **speedkilldefense/**: Defense against speed kills tutorials
- **survival/**: Survival mode tutorials
- **teamstart/**: Team coordination and start tutorials

## Usage

- **Player Education**: Visual guides for learning game mechanics
- **Technique Demonstrations**: Visual examples of advanced techniques
- **Mode Explanations**: Illustrations of different game modes
- **Interactive Tutorials**: Visual elements for interactive tutorial systems
