# textures/tutorials/survival/ Directory

## Summary

Survival mode tutorial textures for Armagetron Advanced.

## Details

This directory contains textures and visual guides specifically for the Survival game mode tutorials. Survival mode tests players' ability to last as long as possible in increasingly difficult situations.

## Technologies

- **Image Formats**: PNG, JPG
- **Purpose**: Survival mode instruction
- **Content**: Visual explanations of survival concepts

## Tutorial Focus

- **Survival Mechanics**: How survival mode works
- **Endurance Strategies**: Techniques for lasting longer in survival mode
- **Difficulty Progression**: Understanding how difficulty increases over time
- **Survival Tactics**: Specialized tactics for survival scenarios
- **Scoring**: How survival mode scoring works
