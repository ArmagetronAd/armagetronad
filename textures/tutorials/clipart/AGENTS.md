# textures/tutorials/clipart/ Directory

## Summary

Clipart-style tutorial graphics and generic tutorial elements for Armagetron Advanced.

## Details

This directory contains clipart-style graphics and generic visual elements used throughout the tutorial system. These images provide reusable graphical components that can be used across different tutorials.

- **Image Formats**: PNG, JPG
- **Style**: Clipart-style, simple and clear graphics
- **Purpose**: Generic tutorial elements and reusable graphics

## Integration

- **Used by**: Multiple tutorial systems for consistent visual elements
- **Resource System**: Loaded as needed for tutorial displays
