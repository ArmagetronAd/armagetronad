# www-root/css/ Directory

## Summary

Cascading Style Sheets for Armagetron Advanced's web interfaces.

## Details

This directory contains CSS stylesheets that define the visual appearance and layout of Armagetron Advanced's web-based interfaces. These stylesheets provide consistent theming and styling across all web pages served by the game's built-in HTTP server.
