# resource/binary/Lucifer/ Directory

## Summary

Lucifer theme binary resources for Armagetron Advanced.

## Details

This directory contains pre-processed binary resources for the Lucifer theme in Armagetron Advanced. The Lucifer theme provides a specific visual style and set of textures for the game.

## Directory Structure

```
.
└── sick/               # Lucifer sick theme variant
    └── floor-1.aatex.png  # Sick theme floor texture
```

## Technologies

- **File Types**: Pre-processed image files
- **Theme**: Lucifer visual theme
- **Purpose**: Theme-specific textures and assets

## Integration

- **Theme System**: Used when Lucifer theme is selected
- **Resource Loading**: Loaded by resource system when theme is active
- **Fallback**: May provide alternative textures for specific theme variants

## Usage

- **Theme Selection**: Resources loaded when Lucifer theme is active
- **Visual Customization**: Provides the unique visual style of the Lucifer theme
- **Performance**: Pre-processed for efficient loading
