# resource/binary/Lucifer/sick/ Directory

## Summary

Lucifer sick theme variant resources for Armagetron Advanced.

## Details

This directory contains pre-processed textures and resources for the "sick" variant of the Lucifer theme. The sick variant provides alternative visual elements within the Lucifer theme family.

## Directory Structure

```
.
└── floor-1.aatex.png  # Sick theme floor texture
```

## Technologies

- **File Types**: Pre-processed texture files (.aatex.png)
- **Theme Variant**: Lucifer sick theme
- **Purpose**: Alternative visual elements for theme customization

## Integration

- **Theme System**: Used when Lucifer sick theme variant is selected
- **Resource Loading**: Loaded by resource system for theme-specific textures
- **Texture System**: Used by rendering system for floor and surface textures

## Usage

- **Theme Customization**: Alternative visual style within Lucifer theme
- **Floor Textures**: Special floor textures for the sick theme variant
- **Performance**: Pre-processed for efficient game rendering
