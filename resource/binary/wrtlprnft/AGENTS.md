# resource/binary/wrtlprnft/ Directory

## Summary

wrtlprnft theme binary resources for Armagetron Advanced.

## Details

This directory contains pre-processed binary resources for the wrtlprnft theme. wrtlprnft is one of the visual themes available in Armagetron Advanced, providing a unique aesthetic and set of textures for the game.

## Directory Structure

```
.
├── floor-1.aatex.png          # Floor texture for the theme
├── benboisclock-1.aatex.png  # Ben Bois clock texture
├── gauge_horizontal_filled-1.aatex.png  # Filled horizontal gauge
└── gauge_horizontal-1.aatex.png       # Horizontal gauge texture
```

## Technologies

- **File Types**: Pre-processed image files (.aatex.png)
- **Theme**: wrtlprnft visual theme
- **Purpose**: Theme-specific textures and UI elements

## Resource Types

- **Floor Textures**: Game floor/arena textures
- **UI Elements**: User interface textures (gauges, clocks)
- **Game Assets**: Theme-specific game visual elements

## Integration

- **Theme System**: Used when wrtlprnft theme is selected
- **Resource Loading**: Loaded by resource system for theme-specific assets
- **UI Rendering**: Used by UI system for theme-consistent interface elements

## Usage

- **Theme Selection**: Resources loaded when wrtlprnft theme is active
- **Visual Customization**: Provides the unique visual style of the wrtlprnft theme
- **Performance**: Pre-processed for efficient loading and rendering
