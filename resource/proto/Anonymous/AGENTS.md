# resource/proto/Anonymous/ Directory

## Summary
Resource files from anonymous contributors.

## Details

The Anonymous directory contains prototype resource files contributed by anonymous authors. These resources include various geometric shapes and patterns used in the game.

```
├── polygon/             # Polygon-based resources
│   └── regular/         # Regular polygon resources
└── shapes/              # Various shape resources
```
