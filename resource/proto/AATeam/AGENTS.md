# resource/proto/AATeam/ Directory

## Summary
Resource files contributed by AATeam.

## Details

The AATeam directory contains prototype resource files created by the AATeam contributor group. These include map definitions and other game assets.

## Directory Structure

```
.
├── map-0.2.8.0.dtd      # Map definition DTD for version 0.2.8.0
└── map-0.2.8.0_rc4.dtd  # Map definition DTD for version 0.2.8.0 RC4
```

## Technologies

- **Formats**: DTD (Document Type Definition)
- **Purpose**: Map and level definitions

## Key Patterns

- Version-specific resource definitions
- XML-based map configuration
